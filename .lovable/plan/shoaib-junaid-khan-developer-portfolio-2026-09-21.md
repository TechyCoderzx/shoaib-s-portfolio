# Shoaib Junaid Khan — Developer Portfolio

## Goal
Build a complete, responsive single-page portfolio that adapts the supplied “black velvet constellation” reference into an honest student-developer identity. The result will emphasize current learning, verified projects, and room to grow without inventing experience or links.

## What I’ll build
- A sticky navigation with active-section tracking, mobile menu, theme switcher, resume access, and smooth scrolling.
- A first screen with Shoaib’s name, student/software-engineering positioning, personal microcopy, four clear actions, profile-image placeholder, and a restrained technical particle/constellation treatment.
- About, interactive categorized skills, featured projects, expandable PulseTrust_ case study, C++ game-engine work-in-progress, “What’s Next,” hackathon, experience-so-far, education, milestones, developer activity, contact, and footer sections.
- Clear placeholders for every missing image, video, repository, social profile, email, phone number, and resume; unavailable actions will be visibly marked rather than opening broken links.
- A contact form that validates input and clearly explains that sending is not connected yet.
- Dark and intentionally designed light themes, persisted in the browser.

## Visual direction
- Preserve the reference’s spacious editorial composition, oversized lightweight typography, black-void dark theme, electric violet actions, amber accents, and sparse constellation details.
- Adapt the reference for a recruiter-friendly portfolio with readable information density, restrained outlined project surfaces, small monospace metadata, purposeful status indicators, and no fake dashboards or proficiency percentages.
- Use a responsive asymmetrical layout on large screens and deliberate single-column sequencing on mobile.

## Technical approach
- Keep the existing TanStack Start foundation required by the project while implementing the experience as a self-contained React page with browser-native interaction patterns.
- Centralize editable portfolio content and placeholder URLs in one configuration module.
- Build small reusable interface pieces for buttons, labels, project blocks, and section headers.
- Define all visual tokens and motion rules in the global design system, including reduced-motion support and both theme palettes.
- Add page-specific title, description, Open Graph, and Twitter metadata.
- Add a README section covering asset replacement, resume/social links, future projects, and deployment.

## Validation
- Check the live page at desktop and mobile sizes in both themes.
- Exercise navigation, mobile menu, skill filters, case-study expansion, placeholder actions, contact validation, and back-to-top behavior.
- Verify no horizontal overflow, broken internal links, console errors, or failed builds.
